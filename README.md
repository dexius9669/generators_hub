# Генераторы

Разводящая страница к трём генераторам.

Открыть: https://dexius9669.github.io/generators_hub/

## Генераторы

- **Dungeon Gen** — https://dexius9669.github.io/pages/Dungeon_Gen.html
  Генератор подземелья для соло-игры «вслепую» (OD&D).
- **Генератор гекскроула** — https://dexius9669.github.io/hexcrawl/
  Заселение, карта, встречи, сокровища и путешествие («Dragons at Dawn»).
- **Инструменты Тони Бата** — https://dexius9669.github.io/tony_bbath_gen/
  Варгейм-кампания: личности, экономика, гексы, осады, бой, погода, движение,
  разведка, снабжение, события.

Неофициальные фанатские инструменты, не связаны с правообладателями.

# Генераторы

Разводящая страница к пяти генераторам.

Открыть: https://dexius9669.github.io/generators_hub/

## Генераторы

- **Dungeon Gen** — https://dexius9669.github.io/dungeon_gen_1/Dungeon_Gen.html
  Генератор подземелья для соло-игры «вслепую».
- **Генератор гекскроула** — https://dexius9669.github.io/hexcrawl/
  Заселение, карта, встречи, сокровища и путешествие.
- **Инструменты Тони Бата** — https://dexius9669.github.io/tony_bbath_gen/
  Варгейм-кампания: личности, экономика, гексы, осады, бой, погода, движение,
  разведка, снабжение, события.
- **Генератор персонажей — The Mighty Tatzelwurm** — https://dexius9669.github.io/mt_chargen/
  Пошаговое создание героя: суть, вдохновение (d66), культура, аспекты, предметы
  и инвентарь.
- **Старый Dungeon Gen (DB)** — https://dexius9669.github.io/dungeon_gen_db/
  Первый вариант генератора на тех же таблицах — эталон движка нового Dungeon
  Gen (нужен интернет для CDN Tailwind).
